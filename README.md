# ⚔️ Flora Duel: แข่งจัดแจกันดอกไม้กับ Algorithm Bot
> เกมฝึกทักษะและเรียนรู้ **Sorting Algorithm** ในรูปแบบ **"แข่งกับ Algorithm ที่ทำงานอยู่ตรงหน้าโดยดูขั้นตอนของมัน"**  
> มี **กติกาชัดเจน, ผลแพ้ชนะ และระบบคะแนนที่สมบูรณ์** เล่นได้จริงตั้งแต่เริ่มจนจบ

---

## 📋 กติกา ผลแพ้ชนะ และระบบคะแนน (Game Rules & Scoring System)

### 1. กติกาการแข่งขัน (Rules)
- ทั้งคุณและ AI Bot จะได้รับแจกันดอกไม้ 6 ใบ ที่มีความสูงแบบสุ่มเท่ากันทุกประการ
- **เป้าหมาย:** จัดเรียงแจกันดอกไม้ตามความสูง **จากเตี้ยไปสูง (ซ้าย ➔ ขวา)** ให้เสร็จก่อนบอท
- **วิธีการเล่น:** คลิกแจกันใบแรก แล้วคลิกใบที่สองเพื่อ **สลับตำแหน่ง (Swap)**

### 2. ผลแพ้ชนะ (Win / Loss Condition)
- 🏆 **คุณชนะ (Victory):** หากคุณสลับแจกันดอกไม้จนเรียงจากเตี้ยไปสูงได้ถูกต้องครบทั้ง 6 ใบ ก่อนที่บอทจะทำงานเสร็จ
- 🤖 **บอทชนะ (Defeat):** หากบอทดำเนินตามขั้นตอนของอัลกอริทึม (Bubble Sort หรือ Selection Sort) จนจัดเรียงเสร็จสมบูรณ์ก่อนคุณ

### 3. ระบบคะแนนชัดเจน (Score Breakdown)
- **คะแนนเริ่มต้น:** 1,000 คะแนน
- **เมื่อชนะบอทได้:**
  - ฐานคะแนนชัยชนะ: **+500 แต้ม**
  - โบนัสความเร็ว (Speed Bonus): คำนวณจากเวลา ยิ่งจัดเสร็จเร็วยิ่งได้แต้มเยอะ (**+50 ถึง +300 แต้ม**)
  - โบนัสประสิทธิภาพ (Optimal Moves): ยิ่งสลับน้อยครั้ง ยิ่งได้คะแนนโบนัส (**+50 ถึง +200 แต้ม**)
- **เมื่อแพ้บอท:** หักคะแนน **-200 แต้ม**
